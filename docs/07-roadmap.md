# 07 · Implementation Roadmap

| Phase | Scope | Status |
|---|---|---|
| **1 – Foundation** | Project setup, DB + migrations + seed, Entra multi-tenant auth + dev login, tenant allow-list, user management, org structure, RBAC + data scope, Admin & User portals, dashboards (basic), ticket create/list/detail, categories, routing rules, support teams, basic workflow, attachments, in-app notifications (stored), audit log, settings, Docker | ✅ Delivered |
| **2 – Workflow** | Assignment/reassignment/transfer + escalation with full history, ticket field editing, main owner team + supporting teams, sub-tasks (create/assign/status/edit/history/attachments, required/optional, due dates), task drawer, My/Team/All/Overdue Tasks views, task progress, required-task resolution gating, unified filterable timeline, task KPIs | ✅ Delivered |
| **3 – Communication** | Socket.IO custom server (+ optional Redis adapter), ticket chat (public + internal notes), image/file attachments, read receipts & unread counters, Support Chat / Messages inboxes, chat search, realtime notifications & toasts, live ticket refresh, notification settings, first-response & requester-reply automation; email/Teams channels defined (delivery in Phase 6) | ✅ Delivered |
| **4 – SLA** | SLA profiles & per-priority targets (business hours / 24×7), business-hours calendars (timezone, split shifts) & holidays, pause conditions per profile, pause-aware response & resolution clocks with target snapshot, On Track/Warning/Breached/Paused/Completed states, SLA card & events, SLA job (warnings, breaches, escalation rules, overdue tasks, auto-close) with multi-instance lease, admin editors, "Run SLA check now" | ✅ Delivered |
| **5 – Dashboard** | Management, Team, My work (agent), SLA, Ticket aging and Workload dashboards; 12 KPIs; trend, SLA performance, aging (5 buckets × priority), workload; breakdowns by status/category/subcategory/team/priority/branch/department; filters (date range, company, department, branch, team, category, subcategory, priority, status, agent) with drill-down; reports with CSV export (`report.export`) | ✅ Delivered |
| **6 – Advanced** | **6A** Major incidents (declare, status updates/communication log, link/unlink child tickets, resolve with cascade, "I'm affected too", known-issues banner, incident dashboard) + branch impact (scope, impacted branches, affected users); **6B** Knowledge base (drafts/publish/archive, convert resolved tickets, FTS + Thai substring search, deflection on create form, feedback, safe Markdown); **6C** Approval workflow (policies per category/subcategory, multi-step manager/specific-user chains with fallback, SLA paused while pending, workflow gate, My Approvals); **6D** Integrations: Microsoft Graph directory sync, Microsoft Teams Adaptive Cards via outbox, IT asset lookup (demo + Snipe-IT-compatible REST), Power BI read-only feeds with hashed API tokens | ✅ Delivered (external services verified against local mocks only) |
| **7 – Hardening** | Nonce-based CSP, Redis rate limiting + trustworthy client IPs + per-IP limits, access review & expiry notices, audit export/archival, Defender for Storage malware gate, container hardening & readiness probe | ✅ Delivered (image build not verifiable in this sandbox) |

## Deferred / candidates
- Category task templates (auto-create tasks from `Category.workflowRules`, e.g. the POS checklist) — candidate for a small follow-up.
- Email notification channel (not in scope of Phase 6).
- Teams bot / actionable messages (approve from Teams) — current integration is one-way channel cards.
- Graph-based Teams *chat* notifications to individuals (needs delegated/RSC permissions).
